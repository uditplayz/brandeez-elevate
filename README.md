# Task 1 — Responsive Landing Page

A clean, modern, and minimalistic responsive landing page built with semantic HTML5 and CSS3.

## What’s included

- **Header / Navbar** – sticky, with logo and navigation links (Home, About, Contact, Follow Us).
- **Hero section** – eyebrow text, large display heading, description, and two call-to-action buttons.
- **Short About & Contact sections** – for a complete single-page experience.
- **Footer** – brand name, social links (GitHub, LinkedIn, Twitter/X), and copyright.
- **Fully responsive** – collapses the navbar into a hamburger menu on mobile and stacks the hero layout.
- **Modern CSS features** – custom properties (variables), CSS Grid, Flexbox, `clamp()` for fluid typography, `backdrop-filter`, and `prefers-reduced-motion` support.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `style.css`  | All styling, responsive rules, and design tokens |

## How to run

1. Download or clone the repository.
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
3. Resize the browser window to see the responsive behaviour.

Optionally, use the **Live Server** extension in VS Code for auto-reload during development.

## Design notes

- **Colour palette**: warm near-white background (`#f7f7f5`), dark ink text (`#1a1a1a`), muted blue accent (`#3b6ea5`).
- **Typography**: Playfair Display for headings, Inter for body text.
- **Layout**: CSS Grid for the hero split, Flexbox for the navbar and footer alignment.
- **Breakpoints**: 768 px (tablet / mobile nav) and 480 px (small phones).

## Browser support

Works in all evergreen browsers that support CSS custom properties, Grid, and Flexbox.
